🚀 How to Practice with this Repository (Beginner's Guide)

Welcome! If you have zero coding knowledge, don't worry. Follow these simple steps to get started with Python.

Step 1: Create a GitHub Account & Fork the Repo

1. Go to github.com and create a free account.
2. Come back to this project page and click the "Fork" button at the top right corner. This makes a copy of this project into your own account.

Step 2: Install Essential Software

1. Download and install VS Code (Code Editor) from here.
2. Download and install Git from here.
3. Download and install Python from here (Make sure to tick "Add Python to PATH" during installation!).

Step 3: Clone the Repository to Your Computer

1. Open VS Code.
2. Go to Terminal > New Terminal in the top menu.
3. Go to your forked GitHub repository, click the green "Code" button, and copy the web URL.
4. In the VS Code terminal, type git clone [Paste the URL here] and press Enter.

Step 4: Open and Run Your First Python File

1. In VS Code, go to File > Open Folder and select the folder you just downloaded.
2. Find a file ending with .py (e.g., hello.py) and open it.
3. Click the Play (Run) button at the top right corner of VS Code to run the code!
4. You will see the output in the terminal at the bottom.
